# 后续执行清单

更新时间：2026-10-11

## 已完成的采集资产

1. **OpenClaw 安全预警事件（E02）**：已形成候选根帖、可见评论、回复和转发数据，以及正式实验工作簿。
2. **AI 照片获得摄影比赛第一名事件（E11）**：已检查 37 条候选根帖。正式工作簿记录了 419 条评论节点、139 条回复节点、264 条转发节点和 42 条排除节点。平台未展示的内容被明确标记为可见性缺口，未做虚构补全。

## 下一阶段：人工标注与第一次训练

1. 从 E02 与 E11 的 `emotion_eligible=1` 文本中按事件、根帖热度、节点类型和传播阶段分层抽样。
2. 两名标注者独立标注 `anger` 与 `fear`，允许双标签和双零标签。
3. 先共同试标 50 条，修订标注指南；随后独立标注至少 500 条并计算 Cohen's Kappa。
4. Kappa 达到 0.75 后扩展到 1,500—2,000 条，按 `root_post_id` 分组切分训练、验证、测试集。
5. 使用 `google-bert/bert-base-chinese` 进行双 Sigmoid 输出微调，报告 Anger/Fear 的 Precision、Recall、F1、Macro-F1 和概率校准。
6. 用通过验收的阶段模型对 E02、E11 全部有效文本输出 `P(anger)`、`P(fear)`。

## 第三事件与最终模型

1. 固定韩国 Deepfake 性暴力与女性求助事件的时间边界、热搜话题、同义词和排除词。
2. 采用与前两个事件相同的数据表字段和平台可见性记录规则采集根帖、评论、回复和转发。
3. 将三事件的人工标注语料扩展至 5,000—8,000 条，重新训练论文最终模型。
4. 使用按事件留一测试检验跨事件泛化能力。

## 正式分析与论文输出

1. 用根帖发布后前 6 小时文本计算早期 `AngerShare`，以 0.60/0.40 划分愤怒主导、恐惧主导和混合型，并以 0.55/0.65 做稳健性检验。
2. 计算级联规模、最大深度、最大宽度、一级传播占比和可恢复关系中的结构病毒性。
3. 计算新增互动热度的达峰时间、峰值速度、半衰期和长尾比例。
4. 计算评论转发比、转发倾向、回复率与评论树深度。
5. 分事件进行非参数比较与回归分析，报告效应量和置信区间；不将相关性写成因果关系。
6. 最后以“事件 × 时间窗口”为单位构建熵权—ABC 风险预警指标。

## 研究约束

- 只使用平台实际可见内容，标称互动量与已采集节点数分开保存。
- 不向仓库提交 Cookie、账号名、手机号或其他直接可识别信息。
- 默认转发文本如“转发微博”不作为情绪训练样本；纯表情文本进入排除表。
