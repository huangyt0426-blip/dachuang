# Anger/Fear 多标签标注规范 v0.1

## 标注单位

以一条可独立理解的帖子或评论为单位。若回复严重依赖上文，应同时提供 `context_text`，但只标注当前文本表达的情绪。

## 标签定义

### anger = 1

文本体现对可归责对象的不公评价、谴责、攻击、追责或惩罚倾向。责任对象可以是公司、平台、政府、开发者、某类群体或具体个人。

典型证据：荒唐、可恶、无耻、必须负责、抵制、追责、凭什么、又在割韭菜。

仅陈述“发生了错误/事故”而没有愤怒表达，不标 anger。

### fear = 1

文本体现对伤害、不确定未来、失控、被骗、失业、隐私泄露或自身/他人安全的担忧、害怕、恐慌或回避倾向。

典型证据：害怕、担心、恐慌、不敢、会不会、以后怎么办、失控、细思极恐。

单纯讨论“风险”概念或转述他人担忧，不自动标 fear；需要判断作者是否表达或认同该情绪。

## 四种合法组合

- `0,0`：两者均无，包括中性信息、快乐、悲伤、厌恶但无追责倾向等。
- `1,0`：愤怒主导。
- `0,1`：恐惧主导。
- `1,1`：既谴责责任主体又表达对伤害/未来的担忧。

## 边界规则

1. 讽刺：根据真实语用判断；无法确定时标记 `uncertain=1`，进入仲裁。
2. 引语：仅引用他人情绪且作者不认同，当前文本不标；作者明确附和则标。
3. 否定：如“我并不担心 AI 失业”不标 fear。
4. 条件句：如“如果不监管，早晚会出事”通常可标 fear；纯技术假设不标。
5. 脏话：有明确归责/攻击对象可标 anger；无对象的口头语不自动标。
6. 转发空文本、广告、机器人内容、无法识别语言：设 `valid=0`，不进入训练集。

## 质量控制

- 两名标注者独立标注，不得讨论后再提交首轮结果。
- 先做 200 条试标，分别计算 anger、fear 的 Cohen's kappa。
- 每类 kappa 目标不低于 0.75；低于目标时修改规则并重做试标。
- 正式标注中随机抽取 10% 复核；冲突由第三人仲裁。
- 数据切分必须按 `event_id` 分组，不能随机把同一事件的近重复文本分到训练集和测试集。
