# AI风险事件与关键词表（2026-08-17）

## 使用原则

1. 事件必须有可核验来源、明确时间窗和可识别责任主体。
2. 主检索式只使用“事件词+风险事实词”，不使用“愤怒、害怕、恐惧”等情绪词，防止标签泄漏。
3. 原始采集时保存命中的具体关键词、采集时间和平台，不要只保存正文。
4. 每个事件单独设置采集上限，避免单一大事件控制整个训练集。
5. 第一轮只采优先级1事件；优先级2用于扩充和跨事件测试。

## 检索组合方式

每个事件按笛卡尔组合生成检索式：

```text
核心词之一 + 风险词之一 - 排除词
```

例如OpenClaw事件可以分成多个窄检索，而不是一个超长表达式：

```text
OpenClaw 密钥泄露
OpenClaw 公网暴露
OpenClaw 越权
龙虾智能体 数据泄露 -小龙虾 -美食
```

## 首轮采样配额

每个优先级1事件建议先取得：

- 原帖：100至200条；
- 评论/回答：300至600条；
- 合计：约500条；
- 六个事件总计：约3000条原始文本。

清洗去重后随机抽取每事件100至150条进入人工试标，最终得到约600至900条首轮标注数据。
